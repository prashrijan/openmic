# Retrospectives

Post-milestone retros. Written after each meaningful release (v0.1, v0.2, ...) or when a significant course-correction happens.

Each retro answers four questions:

1. **What worked well?** — keep doing.
2. **What didn't work?** — stop doing.
3. **What surprised us?** — learnings that weren't in the plan.
4. **What will we change next milestone?** — concrete commitments.

File naming: `YYYY-MM-DD-milestone.md` (e.g., `2026-11-30-v0.1-launch.md`).
